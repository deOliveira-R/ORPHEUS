**The surgical fix vs the prior wrong approach**:

| | Prior (`ad37ca0`, REVERTED) | Resolution A (this commit) |
|---|---|---|
| `StreamingOperator` constructor | `(sn_mesh)` | `(sn_mesh, sigma_t)` |
| `StreamingOperator.apply(ψ)` | `matvec(ψ, σ_t=0)` | `matvec(ψ, σ_t) − σ_t⊙ψ` |
| Composition holds on curvilinear | NO (3-13% rel error) | YES (bit-exact) |
| xfails | 6 (sphere/cylinder × 3) | 0 |

The matvec is RATIONAL in σ_t for curvilinear via Hébert §3.9.4 Eq. 3.434's
Carlson coupled-pole seed denominator `dr·σ_t + 2`. Setting σ_t=0
degenerates the seed and produces a different operator. Resolution A
calls matvec at the FULL σ_t, then subtracts the cell-collision term
post-matvec at the packed-vector level. By construction:

```
L.apply(ψ)       := M(ψ; σ_t) − σ_t ⊙ ψ_packed
C.apply(ψ)       := σ_t ⊙ ψ_packed
(L + C).apply(ψ)  ≡ M(ψ; σ_t)   [bit-exact, algebraic identity]
```

## Architectural notes — Pattern alignment

This substep manifests several coding-elegance patterns at once:

- **Pattern 1 (algebra match via dunders)**: `(L + C).apply(ψ)` reads
  as `L.apply(ψ) + C.apply(ψ)`. The Phase G four-operator algebra's
  spell `L + C - S - F/k` operates naturally on these leaves.
- **Pattern 2 (single source of truth)**: the matvec primitives in
  `orpheus/sn/operator.py` remain THE source of the discrete operator's
  numerical behaviour; both `SNStreamingOperator` and the new
  `StreamingOperator + CollisionOperator` route through them. No twin
  implementation.
- **Pattern 4 (illegal states unrepresentable)**: both leaves carry
  σ_t at constructor time. `StreamingOperator(sn_mesh)` without σ_t
  cannot be constructed — the dataclass field is required positional.
  Curvilinear L is intrinsically σ_t-coupled (Hébert §3.9.4); the
  type system encodes this.
- **Pattern 7 (normalise at the definition site)**: σ_t is fixed
  once at the operator constructor; downstream consumers (Krylov
  inner loops, future within-group sweep) never re-introduce σ_t
  conventions.

The subtractive definition is **principled per
`vv-principles` §"Bit-identity vs principled-equivalence"**: the
named intermediate `σ_t ⊙ ψ` IS the cell-collision rate density (a
reactor-physics quantity); the matvec result is the full operator
action; their difference IS the streaming+redistribution component.
Three named, inspectable, unit-bearing intermediates, composed via
`+/−` — math reads as code.
