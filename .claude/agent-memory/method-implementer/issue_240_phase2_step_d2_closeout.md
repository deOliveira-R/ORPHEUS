## What landed

The three generic affine reconstruction ops moved from the free-function module
`orpheus/sn/spatial/affine_closure.py` → `@staticmethod`s on `CellUpdateBase`
(`orpheus/sn/spatial/cell_update.py`, the DiscretizationScheme base; D3 renames it):

* `source_emission(QV, inverse_denom, w) -> b = QV·inverse_denom/w`
* `cell_average(face_in, face_out, w) -> (1−w)·in + w·out`
* `outgoing_face_from_average(psi_bar, face_in, w) -> (ψ̄ − (1−w)·in)/w`

They are pure functions of in/out/w (no instance state) — the GENERIC
advection–reaction reconstruction (Step↔upwind w=1, DD↔central/box w=½,
LD↔DG-P1-upwind w=1/(1+k)); they belong on the scheme base so the future
diffusion scheme subclasses it and inherits them. `affine_closure.py` was
**deleted** (`git rm`) once emptied.

## The LD `w`-fold (elegance-enforcer D1 carry-forward)

of truth — Pattern 2).
