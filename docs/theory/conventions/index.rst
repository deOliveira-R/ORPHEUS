===========
Conventions
===========

**Read this part first.** It is the one part with no counterpart in the
literature, and the one whose absence produces the worst failure class in a
transport code: *code that runs, converges, and is wrong by a constant.*

A conventions crosswalk is not pedantry here — the published canon
does not agree with itself, and largely does not warn you: the same
weight symbol changes normalization five pages apart, the
:math:`(2\ell+1)` prefactor changes size with dimensionality, and the
scattering arrow points opposite ways across the standard texts. Each
is a live convention trap with a catcher in the ERR catalog, and each
is pinned — with equation numbers — in the :ref:`literature crosswalk
<notation-crosswalk>` and on :doc:`normalization`. Every import of an
external equation must cross the boundary through this part.
