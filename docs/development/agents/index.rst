Agent role blocks
=================

One page per project agent: its role (Key or Support), the workflow phases it
owns, the supports it may call, and its return contract. Each page is
generated into the agent's ``AGENT.md`` between ``GENERATED`` markers; the
rest of an ``AGENT.md`` (tools, model, memory, the harness-specific header) is
maintained by hand.
