# `spn_method/` — Simplified P_N (SP_N) — reserved

**Status:** empty / placeholder. Implementation deferred.

## Intent

Asymptotic reduction of the P_N equations in slab geometry, generalised
to multi-D. SP_N occupies the bridge between diffusion and full
transport — pedagogically valuable for ORPHEUS's "teaching tool"
mission, and a useful intermediate-fidelity reference for production
solvers.
