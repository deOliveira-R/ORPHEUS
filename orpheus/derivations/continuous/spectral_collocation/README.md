# `spectral_collocation/` — Pure spectral collocation — reserved name

**Status:** empty / placeholder. **Reserved folder name — no concrete
reference yet.**

## Intent

Pure spectral collocation methods (Chebyshev / Gegenbauer / Jacobi
families) for the transport equation. Most useful as Branch-1
(symbolic + spectrally-converged numerical) verification rather than as
a Branch-2 production solver.

## Notes on candidate references (NOT all local)

* **Garcia, R.D.M., Siewert, C.E. (1979 / 1980s).** Chebyshev /
  Gegenbauer collocation work for transport theory. Some of this
  family lives on HAL; not all PDFs are local.
* **Hauser, M., Pomraning, G.C. (1980s).** Spectral collocation for
  transport problems with high-anisotropy scattering.

This folder is reserved for taxonomic completeness — when a concrete
reference is selected and a benchmark identified, the README will be
upgraded to the standard "canonical reference + local PDF path" format.
