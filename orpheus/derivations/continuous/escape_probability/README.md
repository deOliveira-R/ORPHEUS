# `escape_probability/` — Escape-probability methods — reserved

**Status:** empty / placeholder. Implementation deferred.

## Intent

Wigner–Seitz cell escape probabilities — the resonance-self-shielding
ancestor of collision-probability methods. Used heavily in lattice
physics (resonance treatments, multi-group cross-section condensation
for thermal reactors). Related to but structurally distinct from
[`flat_source_cp/`](../flat_source_cp/), which is the flat-source-per-
region collision-probability formulation.
